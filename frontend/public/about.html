AI、隐私与反馈

预测与赛事分析

胜平负概率和预计进球来自足球模型。标有“AI 生成”的报告和追问由 DeepSeek 根据本项目的公开赛事资料组织成文。“基础数据解读”使用本项目模板。每份报告给出适用的比赛、预测阶段、数据截止时间和依据。伤停、首发等未收录的信息会显示资料缺失。

提问时会使用什么信息

实时分析会向服务端提交比赛编号、问题、当前报告版本及最近三轮对话；启用 DeepSeek 时，提供商会收到处理该问题所需的信息。请只填写赛事问题。本站应用默认仅记录请求编号、错误类型、延迟及用量，限额账本保存匿名访客标识，共享报告公开可读。托管平台及模型服务按各自政策处理网络请求。

免费公测为报告及追问分别预留额度。模型服务中断或当期额度用完时，已发布报告和基础数据仍可阅读。

数据来源

历史比分来自 openfootball（CC0），当季合并数据注明 OpenLigaDB（ODbL 1.0）。公开市场信息使用派生概率。每次赛程核准、预测冻结和比分修订可在比赛时间线核对。

问题反馈

发现时间、数字或界面有误，可在 GitHub 提交反馈。附上比赛链接、页面显示的数据截止时间和重现步骤有助于定位问题。
