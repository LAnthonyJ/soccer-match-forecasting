# 球迷手机体验验收

在 iPhone Safari、Android Chrome 分别从无缓存首页打开同一批次。记录设备、系统、浏览器、测试时间和批次标识。对五位首次使用者分别执行下表；一人操作时其他人不观看。主持人选取当前批次实际存在的球队和比赛，开始任务时再告知球队名称。

| 给参与者的任务 | 完成信号 |
|---|---|
| 找到指定球队的下一场英超，告诉我对手和几点开球。 | 指出正确对手、日期和当地时间；待定场次要能说出时间待定。 |
| 打开一场双方胜率接近的比赛，用自己的话说谁略占先、差多少。 | 指出正确方向和百分点差，能识别当前预览或已冻结状态。 |
| 找到上一轮指定对阵的确认比分。 | 在赛程中直接读出两队和比分；若该轮没有确认比分，记录数据缺口，另选有确认比分的过去轮次验证操作。 |

由主持人逐人记录每项任务的耗时、是否独立完成和第一次点错的位置。每项至少四人独立在 30 秒内完成。完成后请参与者指出最难辨认的文字或操作，再归类实际遇到的问题。
